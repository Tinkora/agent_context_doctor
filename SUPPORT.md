# Support

[简体中文](SUPPORT.zh-CN.md)

Use GitHub Discussions for usage questions and Issues for reproducible defects.
Include the operating system, tool version, selected host, target layout, exit
status, output format, and a synthetic minimal reproduction.

Never publish real absolute paths, repository names, instruction contents,
configuration values, credentials, or unsanitized host output. The default
redaction is defense in depth, not a substitute for reviewing a report before
sharing it.
